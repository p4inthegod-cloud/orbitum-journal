# Ежедневная аналитика Eternity Trade

Маршрут `GET /api/daily?action=market` собирает данные BTC с Bybit, добавляет Fear & Greed и экономические события, после чего отправляет:

- полный оформленный обзор в Telegram-канал;
- короткий сценарий и вопрос для обсуждения в Telegram-чат.

Vercel Cron запускает маршрут каждый день в `07:00 UTC`, то есть в `10:00 МСК`.

## Переменные Vercel

Обязательные:

| Переменная | Значение |
|---|---|
| `TELEGRAM_BOT_TOKEN` | Токен существующего Telegram-бота |
| `CRON_SECRET` | Длинная случайная строка |
| `ETERNITY_CHANNEL_ID` | `@username` публичного канала или числовой ID |
| `ETERNITY_CHAT_ID` | `@username` группы или числовой ID |

Дополнительные:

| Переменная | Назначение |
|---|---|
| `ETERNITY_CHAT_THREAD_ID` | ID темы, если материалы нужно отправлять в конкретную тему форума |
| `MARKET_BRIEF_SYMBOL` | Торговая пара Bybit; по умолчанию `BTCUSDT` |
| `APP_URL` | Адрес терминала; по умолчанию `https://orbitum.trade` |
| `FINNHUB_API_KEY` | Основной источник экономического календаря; без него используется резервный источник |

Бот должен быть администратором канала с правом публикации. В группе ему нужно разрешить отправку сообщений.

## Безопасная проверка

Вернуть тексты без отправки в Telegram:

```bash
curl -H "Authorization: Bearer $CRON_SECRET" \
  "https://orbitum.trade/api/daily?action=market&dry_run=1"
```

Отправить обзор вручную:

```bash
curl -H "Authorization: Bearer $CRON_SECRET" \
  "https://orbitum.trade/api/daily?action=market"
```

В штатном режиме ручной запуск не нужен: расписание находится в `vercel.json`.

## Тест в личном чате

Пользователь с привязанным Telegram-аккаунтом может отправить боту команду `/markettest`. Бот соберёт живые данные и пришлёт полный обзор только в этот личный чат, не публикуя его в канал или группу.
